# HomeLess News

## 📋 Описание проекта

**HomeLess News** — это веб-агрегатор новостей с возможностью авторизации пользователей, создания личных записей и парсинга актуальных новостей с сайта Lenta.ru. Проект представляет собой многофункциональную платформу для чтения и публикации новостей по различным категориям.

### Основные возможности

- 🔐 **Регистрация и авторизация** пользователей с хешированием паролей
- 📰 **Парсинг новостей** с Lenta.ru по 7 категориям
- ✍️ **Создание собственных новостей** с возможностью установки приватности
- 🏷️ **Категоризация новостей** (экономика, политика, наука, культура, мир, СНГ, путешествия)
- 📱 **Адаптивный дизайн** на Bootstrap
- 🗑️ **Редактирование и удаление** своих новостей
- 📊 **RESTful API** для работы с новостями и пользователями

## 🚀 Установка и запуск

### Требования

- Python 3.7 или выше
- pip (менеджер пакетов Python)

### Установка зависимостей

```bash
pip install flask flask-login flask-restful flask-wtf beautifulsoup4 requests sqlalchemy sqlalchemy-serializer
```

### Запуск приложения

```bash
python main.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## 📡 RESTful API

### Эндпоинты для новостей

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/news` | Получить все новости |
| GET | `/api/news/<id>` | Получить новость по ID |
| POST | `/api/news` | Создать новость |
| DELETE | `/api/news/<id>` | Удалить новость |

### Эндпоинты для пользователей (в разработке)

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/users` | Получить всех пользователей |
| GET | `/api/users/<id>` | Получить пользователя по ID |
| POST | `/api/users` | Создать пользователя |

### Примеры запросов к API

**Получение всех новостей:**
```bash
curl -X GET http://localhost:5000/api/news
```

**Создание новости:**
```bash
curl -X POST http://localhost:5000/api/news \
  -H "Content-Type: application/json" \
  -d '{"title":"Заголовок","content":"Текст","user_id":1,"is_private":false}'
```

**Удаление новости:**
```bash
curl -X DELETE http://localhost:5000/api/news/1
```
